# Hoverbike Racer — play build
Sci-fi anti-gravity racing in the browser. 8 bikes, 8 alien worlds, physics-only abilities.
Play: https://eddiesk-cell.github.io/hoverbike-racer-play/
Controls: W/S throttle-brake · A/D steer · Shift drift · Q/E side-dash · Space boost (energy) · F ability · C camera · Esc pause. Gamepad supported.
This repo holds only the built game; source is private.
